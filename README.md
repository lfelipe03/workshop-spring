Projeto desenvolvido para fins de estudo e prática com **Java e Spring Boot**.

## Sobre o projeto
Este projeto tem como objetivo praticar os fundamentos do desenvolvimento backend,
utilizando **API REST** e **arquitetura em camadas**, com foco na gestão de objetos
(entidades) e operações básicas de CRUD.

O foco não é um sistema de negócio específico, mas sim o aprendizado das boas práticas
utilizadas em aplicações backend com Spring.

## Conceitos praticados
- Criação de API REST
- Arquitetura em camadas (Controller, Service, Repository)
- Gerenciamento de entidades
- Operações CRUD (Create, Read, Update, Delete)
- Uso do Maven para gerenciamento de dependências

## Tecnologias utilizadas
- Java
- Spring Boot
- Maven
- JPA / Hibernate

## Como executar o projeto
1. Clonar o repositório
2. Importar o projeto como Maven em sua IDE
3. Executar a classe principal da aplicação
